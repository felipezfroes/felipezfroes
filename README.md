## 👋 Sobre mim

Sou estudante de **Engenharia de Software na UniCesumar**, desenvolvedor e criador da **FZF Productions**.

Gosto de aprender construindo projetos reais, principalmente nas áreas de:

- 🎮 Desenvolvimento de jogos com **GameMaker e GML**
- 🌐 Desenvolvimento Front-End
- ⚙️ Automações e ferramentas com **Python**
- 💻 Programação e projetos acadêmicos em **C**
- 🎥 Produção de conteúdo sobre GameDev e desenvolvimento de software

Na FZF Productions compartilho tutoriais, Game Jams, devlogs, projetos e minha evolução como desenvolvedor.

### ⚙️ Papotech Editor

Ferramenta desenvolvida em **Python** para automatizar parte do processo de edição de podcasts.

Inclui processamento de áudio, sincronização, redução de pausas, transcrição com Whisper e geração de marcações para edição.

💻 [Ver projeto](https://github.com/felipezfroes/papotech-editor)
